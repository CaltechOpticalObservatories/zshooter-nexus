# WBS

Work-package abbreviations, scope, and links to the corresponding instrument documentation.

| Work package | Area | Scope and documentation |
| --- | --- | --- |
| MGT | Project management | Planning, coordination, reviews, and project reporting. |
| SYS | Systems engineering | [Requirements](requirements.md), [performance](performance.md), interfaces, and verification. |
| STR | Spectrograph structure | Spectrograph support structure; see [System Architecture](architecture.rst). |
| CAL | Calibration system | Internal sources and light delivery; see [Calibration procedures](procedures/calibration.md). |
| BFA | Beam feed assembly | Front-end beam routing; see [ZFront operations](controls/operations/zfront-zcal.md). |
| VPO / IPO | Visible / infrared pre-optics | Slit relays, ADCs, rotators, and slit viewing; see [ZSpec](zspec_optical.md). |
| VSPEC / ISPEC | Visible / infrared spectrographs | Spectrograph optics, cameras, and detector assemblies; see [ZSpec](zspec_optical.md). |
| ZIMG | ZImager | Imager optics, mechanisms, and detectors; see [ZImager](zimager_optical.md). |
| ELE | Electronics | Control electronics, racks, and connectivity; see [Harnesses](controls/harnesses/index.md). |
| ICS | Instrument control software | Device control, sequencing, and observer interfaces; see [Software](_staged/ics/index.rst). |
| OBS | Observation planning software | Simulation and exposure-time estimates; see [Instrument simulator](simulator.rst). |
| DRP | Data reduction pipeline | Quicklook and science reduction; see [Data Reduction](reduction.rst). |
| AIT | Assembly, integration, and testing | Instrument assembly, alignment, and laboratory verification. |
| GSE | Ground support equipment | Handling, installation, and maintenance equipment. |
| WMKO | Observatory infrastructure | RNAS platform, transport, and facility-service integration. |
| COM | Commissioning | On-sky commissioning and performance verification. |
